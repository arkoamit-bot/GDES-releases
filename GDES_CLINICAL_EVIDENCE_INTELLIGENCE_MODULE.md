# Vision

Transform GDES from a rule-based clinical decision support system into a continuously learning, evidence-driven nephrology intelligence platform.

Every recommendation generated by GDES shall be validated against the latest medical evidence before presentation to the clinician.

The system shall retrieve, analyze, synthesize, compare, and audit medical evidence automatically while maintaining complete explainability and governance.

This module becomes one of the core engines of GDES.

---

# Objectives

The Clinical Evidence Intelligence (CEI) module shall:

- Retrieve the latest peer-reviewed evidence.
- Compare evidence with GDES recommendations.
- Detect conflicting recommendations.
- Verify guideline compliance.
- Produce explainable recommendations.
- Maintain complete audit trails.
- Continuously monitor for new evidence.
- Support future AI providers without architectural changes.

# OpenCode Implementation Instructions

Implement this module as a production-quality bounded context within GDES.

Requirements:

1. Follow Domain-Driven Design and Clean Architecture throughout.
2. Integrate seamlessly with the existing Knowledge Engine, Clinical Governance Layer, RecommendationAudit, Traceability, Prescription Engine, and Patient Registry.
3. Use asynchronous provider orchestration and resilient error handling.
4. Produce structured, explainable outputs suitable for clinician review and regulatory audit.
5. Design every provider as a plug-in implementation of a common interface.
6. Ensure all code is fully documented, type-hinted, tested, and suitable for enterprise deployment.
7. Preserve backward compatibility with all existing GDES functionality.
8. Treat this module as a foundational capability for GDES Version 9 and future AI-enhanced clinical decision support.
